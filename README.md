# 🌾 AgriSathi: The Future of Voice AI for Farmers

[![Powered by Gemini 3](https://img.shields.io/badge/AI-Gemini%203-blueviolet?style=for-the-badge&logo=googlegemini)](https://deepmind.google/technologies/gemini/)
[![LiveKit](https://img.shields.io/badge/Stack-LiveKit-blue?style=for-the-badge)](https://livekit.io/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

**AgriSathi** is a revolutionary multilingual voice agent designed to solve the digital divide for India's 140 million farmers. By integrating **Google Gemini 3** with low-latency telephony, we provide instant, expert agricultural advice over a simple phone call.

---

## ⚡ Why AgriSathi?
- **🎯 Zero Tech Friction**: No app, no internet, no smartphone required. A basic phone call is all it takes.
- **🗣️ Language Sovereignty**: Seamlessly understands Hindi, Hinglish, and regional dialects.
- **🧠 Gemini 3 Brain**: Leverages the world's most advanced reasoning model for hyper-accurate crop advisory.
- **💾 Personalized Memory**: Remembers past conversations, soil types, and crop cycles for every farmer.

---

## 🛠️ The "Magic" Stack
| Component | Technology |
| :--- | :--- |
| **Brain** | **Google Gemini 3** |
| **Orchestration** | **LiveKit Agents** |
| **Ear (STT)** | **Deepgram Nova-3** |
| **Voice (TTS)** | **Cartesia Sonic-3** |
| **Memory** | **Persistent SQLite Bank** |

---

## ✨ Standout Features
- **🌦️ Smart Weather**: Localized planting alerts based on real-time forecasts.
- **🔍 Mandi & Schemes**: Instant voice search for market prices and government aid.
- **🌱 Expert Advisory**: Diagnoses pests and recommends fertilizers via conversation.
- **🔄 Interruption-Resilient**: Natural turn-taking with ultra-low latency.

---

## 🚀 Get Started in 60s
1. **Setup**: `git clone https://github.com/aditya-somani/AgriSathi.git && uv sync`
2. **Configure**: Add your **Gemini 3**, LiveKit, and Voice API keys to `.env`.
3. **Execute**:
   ```bash
   python -m src.main dev
   ```
