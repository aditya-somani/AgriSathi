# 🚀 AgriSathi: Future Roadmap & Ideas

This document tracks potential features and optimizations to move AgriSathi from an MVP to a mature product.

---

## 📅 Phase 2: High-Impact Additions

### 1. Quick Wins (1-2 days each)
- **Mandi Price Tool**: 
    - Integrate with eNAM or Agmarknet APIs.
    - Fetch real-time crop prices based on location.
- **Weather Alerts (Proactive)**:
    - Push notifications/outbound calls for rain or frost alerts.
    - Context: "Sarkar ka alert hai, Lucknow mein kal tej barish hone wali hai."
- **Conversation Memory Upgrade**:
    - Add semantic search (Vector DB) over past conversation summaries.
    - Allow the agent to recall specific questions/advice from last month.

### 2. Medium Effort (1-2 weeks)
- **Multi-Agent Handoff**:
    - Specialized brains for different domains (Crops, Market, Schemes).
    - Use LiveKit's ability to swap agent classes mid-session.
- **Document Processing**:
    - Support for farmers sending/uploading photos (Vision).
    - Extract info from land records, bills, or government IDs.
- **Crop Disease Diagnosis**:
    - Description-based diagnosis tools.
    - Actionable feedback on pesticides and organic remedies.

---

## 🛠️ Performance & Production Optimizations

### 3. Polish & Infrastructure
- **Analytics Dashboard**: 
    - Track common queries, peak call times, and tool success rates.
- **Regional Dialect Support**:
    - Use Cartesia's support for Bengali, Marathi, and specific Hindi dialects (Bhojpuri).
- **Offline/Fallback Intelligence**:
    - Local FAQ retrieval if the LLM provider (Gemini) is slow or down.

---

## 📈 Long-Term Vision

### 4. Ecosystem Integration
- **WhatsApp Integration**:
    - Support for voice notes and text interaction on WhatsApp.
- **FPO (Farmer Producer Organization) Hub**:
    - Tools for groups of farmers to coordinate sales and logistics.
- **Marketplace Connection**:
    - Directly connect farmers to vetted fertilizer/seed vendors.
